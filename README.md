# 🌍 Ayush Travels Website  

This is a simple **HTML project** created as part of an assignment.  
The project is a sample travel website called **Ayush Travels**, showcasing different travel destinations, travel packages, and contact information.  

---

## 📖 Features  

- ✅ **Basic HTML5 Structure** (doctype, head, body, etc.)  
- ✅ **Text Formatting**: bold, italic, underline, strikethrough  
- ✅ **Images** of travel destinations and activities: Eiffel Tower, New York, Taj Mahal, Scuba Diving  
- ✅ **Hyperlinks**:  
  - Internal link (jump to contact section)  
  - External link (Wikipedia Travel Destinations page)  
  - Relative link (to HomePage.html)  
- ✅ **Lists**: ordered, unordered, and definition lists  
- ✅ **Table** displaying travel packages with styled rows  
- ✅ **Contact Section** with email and phone number  
- ✅ **Inline CSS styling** (background color, text colour)

---

🎨 Styling Details
The website uses inline CSS for basic styling:

Background color: Light blue (#f0f8ff)

Text colors: Orange, green, blue, purple, etc. for section headings

Table styling: Alternating row background colors for better readability

Text formatting: <strong>, <em>, <ins>, <del> used for bold, italic, underline, and strikethrough
